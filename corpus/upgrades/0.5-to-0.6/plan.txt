docsys upgrade: docsys/0.5 → docsys/0.6 — the plan

Upgrading to docsys 0.18.0:
- `docsys upgrade` prints the plan; `docsys upgrade --apply --commit` moves the
  tree, one commit per spec version. The items it lists for a person are
  theirs to finish.
- The git gate becomes hard on every tree, and a pull request's check reads
  only what the change does: an error its base already carries is named as
  inherited, with the base's commit, and blocks nothing; an error the change
  adds blocks, in the commit and in the pull request alike (D-136).
- A region that merged changes moved, each of which re-read the text it
  brought, is reported, not an error, naming the changes, until a re-read
  acknowledges the combination; the next pull request that moves the region
  or its page must re-read it. A change that moved a region without a re-read
  is still an error, and names that change (R-111, D-135).
- A code-side `doc:` counts after a comment leader or opening inline code
  (`` `doc: id` ``); one that only opens a line's text is prose from here on,
  so an object key or a typed field is no citation. The plan lists each
  citation that changes meaning (R-072, D-137).
- Where CI installs docsys from its release, the tree gets one installer,
  `.docsys-install` beside `.docsys-version`, which holds the version and its
  archives' sha256 values: CI runs it, and so does a clone with no docsys.
  The workflow's pull request job runs the scoped gate alone, push runs on the
  default branch only, and a merge queue is checked; in a workflow you edited,
  only those lines change, and the plan shows the diff (D-138).

+#!/usr/bin/env bash
+# docsys-install: written by `docsys upgrade` — do not edit; the version and the
+# sha256 values move with the pin, and only `docsys upgrade` moves them (D-138).
+# Installs the docsys release this tree pins, its archive checked against the
+# sha256 values below: CI runs it, and so does a clone with no docsys. It needs
+# curl, tar and sha256sum or shasum, and no credential. It writes the binary
+# under ${DOCSYS_HOME:-~/.docsys}/versions/, where every docsys looks for a
+# pinned version, and links it into ${DOCSYS_BIN_DIR:-~/.local/bin} when no
+# docsys is on the PATH; it changes no file in the repository.
+# --print-dir prints the directory that holds the binary, for a CI PATH.
+set -euo pipefail
+version=0.18.0
+case "$(uname -s)-$(uname -m)" in
+  Linux-x86_64) target=x86_64-unknown-linux-musl sum=1111111111111111111111111111111111111111111111111111111111111111 ;;
+  Linux-aarch64) target=aarch64-unknown-linux-musl sum=2222222222222222222222222222222222222222222222222222222222222222 ;;
+  Darwin-x86_64) target=x86_64-apple-darwin sum=3333333333333333333333333333333333333333333333333333333333333333 ;;
+  Darwin-arm64) target=aarch64-apple-darwin sum=4444444444444444444444444444444444444444444444444444444444444444 ;;
+  *) echo "docsys-install: no release archive for $(uname -s)-$(uname -m); install with cargo: cargo install docsys --version $version --locked" >&2; exit 1 ;;
+esac
+here=$(cd "$(dirname "$0")" && pwd)
+pin=$(head -n 1 "$here/.docsys-version" 2>/dev/null | tr -d '[:space:]' || true)
+if [ "$pin" != "$version" ]; then
+  echo "docsys-install: .docsys-version names ${pin:-no version}, and this installer holds $version — run docsys upgrade --apply, which writes both" >&2
+  exit 1
+fi
+dest="${DOCSYS_HOME:-$HOME/.docsys}/versions/$version/bin"
+if [ ! -x "$dest/docsys" ]; then
+  name="docsys-v$version-$target"
+  tmp=$(mktemp -d)
+  trap 'rm -rf "$tmp"' EXIT
+  curl -fsSL --retry 3 -o "$tmp/$name.tar.gz" "${DOCSYS_RELEASES:-https://github.com/FatihErtugral/docsys/releases/download}/v$version/$name.tar.gz"
+  got=$(cd "$tmp" && { sha256sum "$name.tar.gz" 2>/dev/null || shasum -a 256 "$name.tar.gz"; } | cut -d ' ' -f 1)
+  if [ "$got" != "$sum" ]; then
+    echo "docsys-install: $name.tar.gz hashes to $got, not the $sum this installer pins" >&2
+    exit 1
+  fi
+  tar -xzf "$tmp/$name.tar.gz" -C "$tmp"
+  mkdir -p "$dest"
+  install -m 0755 "$tmp/$name/docsys" "$dest/docsys"
+fi
+if [ "${1:-}" = "--print-dir" ]; then
+  echo "$dest"
+  exit 0
+fi
+if ! command -v docsys >/dev/null; then
+  bin="${DOCSYS_BIN_DIR:-$HOME/.local/bin}"
+  mkdir -p "$bin"
+  ln -sf "$dest/docsys" "$bin/docsys"
+  case ":$PATH:" in
+    *":$bin:"*) ;;
+    *) echo "docsys-install: $bin is not on PATH; add it to your shell profile" >&2 ;;
+  esac
+fi
+echo "docsys-install: docsys $version is installed in $dest"
