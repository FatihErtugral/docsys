# Citation form

This page shows the citation convention; read it before writing a code comment.

An example inside an indented code block is quoted material, not a reference:

    // before: see docs/reference/some-page.md
    // after:  doc: fake-example-id

A citation in prose still resolves — this one is really dangling: doc: really-missing
